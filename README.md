# Heli-Pad (Orbit Family Logistics)

A modern, responsive web application designed for stress-free family handoffs, activity relays, and parental coordination.

## Features

- **Mission Control**: Immediate glance at the next required departure, lead driver, destination, and schedule readiness score.
- **Relay Timeline**: Scannable schedule of the day's activities with route ribbons (`Origin ➔ ETA ➔ Destination`), child badges, transit modes, and departure alerts.
- **AI Route Intelligence**: Proactive scheduling recommendations to resolve handoff conflicts, leverage closer parent locations, bundle grocery stops, and protect family dinner windows.
- **Sunday Reset Sprint**: Step-by-step checklist to import calendars, calibrate traffic buffers, and balance parental workload.
- **Saved Places & Traffic Radar**: Venue parking ease ratings, loading buffer configuration, and live-feel route estimation.
- **Parental Workload Balancing**: Track behind-the-wheel burden between partners and auto-optimize driver assignments based on default starting locations.

## Getting Started

Open `index.html` (or `Orbit_Family_Logistics_Rebuilt.html`) directly in any modern browser. No build steps or external dependencies required.
